Help and troubleshooting

The cat isn't showing up? Nearly always, macOS hasn't let Cat Type notice your typing yet. Start at the top and stop when the cat comes back.

  1. Turn on Input Monitoring
  2. Cat Type isn't in the list
  3. The switch is on, but there's still no cat
  4. The cat disappears in some apps (Secure Keyboard Entry)
  5. On Windows
  6. Still stuck

1. Turn on Input Monitoring

macOS asks you to allow Input Monitoring before any app can notice key presses. Cat Type only counts them to make the cat tap along. It never sees what you type.

The easiest way is the setup window built into Cat Type: click the cat in your menu bar and choose Set Up Input Monitoring…. It opens the right page in System Settings and lets you know the moment it works. To do it by hand:

  1. Open System Settings from the Apple menu.
  2. Go to Privacy & Security, then Input Monitoring.
  3. Turn on the switch next to Cat Type. macOS may ask for your password or Touch ID.
  4. If macOS offers Quit & Reopen, choose it. Cat Type opens again by itself.

Open Input Monitoring settings

That button only works on a Mac. Your browser will ask before it opens System Settings.

2. Cat Type isn't in the list

  1. Make sure Cat Type is in your Applications folder. If you opened it straight from the downloaded disk image, drag it to Applications, eject the disk image, and open it from Applications instead.
  2. In Input Monitoring, click + under the list.
  3. Choose Applications, select Cat Type, and click Open.
  4. Turn on its switch, then quit Cat Type from the menu bar and open it again.

3. The switch is on, but there's still no cat

After an update, macOS can keep the old copy's permission and ignore the new one, even though the switch still looks on. Giving permission again fixes it:

  1. In Input Monitoring, select Cat Type and click − to remove it.
  2. Click + and add Cat Type from Applications again, then turn its switch on.
  3. Quit Cat Type from the menu bar and open it again.

If you prefer Terminal, this clears Cat Type's Input Monitoring entry so you can allow it fresh the next time Cat Type opens:

tccutil reset ListenEvent com.fungusta.cat-type

Also check that the cat isn't simply paused. Click the cat in the menu bar: Enabled should be ticked.

4. The cat disappears in some apps

macOS has a protection called Secure Keyboard Entry. While it is on, no other app can notice your typing, Cat Type included. It switches on by itself while you type into a password field, so the cat staying away there is macOS doing its job. The cat considers this a reasonable boundary.

Trouble starts when an app keeps Secure Keyboard Entry on all the time, or forgets to switch it off. Then the cat vanishes in that app, or everywhere until that app lets go. Common sources:

  • Terminal: open the Terminal menu and untick Secure Keyboard Entry.
  • iTerm2: open the iTerm2 menu and untick Secure Keyboard Entry.
  • Password managers and sign-in prompts can leave it on after you type a password. Close the prompt or quit the app.

Cat Type watches for this. When Secure Keyboard Entry stays on for more than half a minute, it lets you know once, and the menu bar cat names the app holding it until that app lets go.

Find the app that's holding it

Paste this into Terminal. When something has Secure Keyboard Entry on, it prints a line ending in a number, such as SecureInputPID"=1234. When it prints nothing, Secure Keyboard Entry is off.

ioreg -l -w 0 | grep -o 'SecureInputPID"=[0-9]*'

Then put your number in place of 1234 to see the app's name:

ps -p 1234 -o comm=

Turn off Secure Keyboard Entry in that app, or quit it. If you can't tell which app it is, locking your Mac and unlocking it again usually clears it.

5. On Windows

Windows doesn't need any permission for Cat Type. The cat stays hidden while you type in a password field, on purpose. If it never appears, check that Enabled is ticked in the Cat Type menu in the notification area.

6. Still stuck

Open an issue on GitHub with your macOS or Windows version and your Cat Type version (shown under Updates in Settings), and say which of the steps above you tried.
