Privacy policy

Last updated 5 November 2026

The short version

Cat Type never records what you type. It keeps a few counts and your settings on your own computer, and it has no accounts, ads, analytics or telemetry. The only thing it sends over the network is a check for new versions on GitHub.

What Cat Type keeps on your computer

  • Keystroke counts. How many keys you pressed in each hour of each day, so it can show your typing week. Never which keys, never the text, never which app or window you typed in.
  • Your settings and wardrobe. Your cat style, outfit, size, position and other preferences.
  • Earned rewards. Which accessories you have unlocked.

These files stay in a Cat Type folder in your user account's app data (%LOCALAPPDATA% on Windows, ~/Library/Application Support on macOS). They are never uploaded.

How it notices your typing

  • The keyboard listener only works out whether a key was on the left or right of the keyboard, so the right paw can tap. It then discards the key straight away.
  • On Windows, Cat Type asks the system's accessibility features where the text cursor is, so the cat can sit beside it. When it detects a password field, the cat stays hidden.
  • On macOS, it remembers only the position and time of your latest click to place the cat. It never asks which app or control you clicked. macOS asks you to allow Input Monitoring before Cat Type can hear any typing.

What it sends over the network

Only update checks. When the app starts, at most once every 24 hours, and whenever you choose Check for updates, Cat Type asks GitHub (api.github.com) for the latest release. If you choose to install an update, it downloads it from GitHub's release servers. These requests carry the app's version number and nothing else about you: no keystrokes, counts, settings or rewards.

Like any website, GitHub can see the network address the request comes from. GitHub's handling of that is covered by the GitHub General Privacy Statement.

Removing your data

Uninstall Cat Type (the Windows installer includes an uninstaller; on macOS, drag the app to the Bin), then delete the Cat Type folder described above.

This website

  • The site is hosted on GitHub Pages, so GitHub receives the usual request details, such as your network address, when you visit.
  • The text font loads from Google Fonts, so Google receives the same kind of request details. See the Google Privacy Policy.
  • The cat you dress up on the home page is remembered in your browser's local storage, on your device only. It is never sent anywhere.
  • The site sets no cookies and uses no analytics or tracking.

Questions and changes

If this policy changes, the new version will be posted on this page with a new date. For questions, open an issue on GitHub.
