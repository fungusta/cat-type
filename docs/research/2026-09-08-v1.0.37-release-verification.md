# Cat Type v1.0.37 Beta release verification

Published [Cat Type v1.0.37 Beta](https://github.com/fungusta/cat-type/releases/tag/v1.0.37)
at 2026-09-08 06:26:32 UTC. It is a published prerelease, not a draft.
The latest stable release remains v1.0.36; stable installations do not automatically
update to this beta.

The annotated tag resolves to `b9ea7a513bebe691e2634fe2d70ffb0e3277c0d6`.
This includes separate Wardrobe and Achievements tabs, nine new item achievements,
neck/back/ear equipment slots, hidden discoveries, and compatibility/performance fixes.
`IS_BETA_BUILD=True` designates this version for the permanent Beta Buddy achievement
and exclusive purple bandana, as selected by the user.
