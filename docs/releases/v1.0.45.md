# Cat Type v1.0.45

This release stabilizes the native Tk lifecycle and cross-platform settings
layout used by Cat Type.

## What's new

- Hardened Windows Tk root creation and preview shutdown cleanup.
- Made constrained native settings windows keep their scrollbar and responsive
  layout state correctly across Windows, Linux, and macOS.
- Improved CI diagnostics for platform-specific test failures.

## Downloads and updates

Use **Check for updates** in Cat Type, or quit the app before updating manually.
