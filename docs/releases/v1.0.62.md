# Cat Type v1.0.62

This release smooths the rough edges of automatic updates.

## What's new

- **Update prompts you asked for take the keyboard.** After **Check for
  updates**, the prompt comes forward so Return installs and Escape closes it,
  even if an automatic check was already running.
- **Clearer update errors.** Failures read as plain sentences instead of
  system error codes and file paths.
- **Failed installs are no longer silent.** If an update can't be swapped into
  place and the old version reopens, Cat Type says so and posts a
  notification with where to download it.
- **More resilient.** If the update window itself can't open, the cat keeps
  running and the update status links to the download.

## Downloads and updates

Mac users on 1.0.61 can install this with **Install Update**. Users on 1.0.60
or earlier need to install it by hand once. On Windows and Linux, use **Check
for updates** in Cat Type, or quit the app before updating manually.
