# Cat Type v1.0.50

This release gives the settings window a smoother, more modern finish, keeps
your cat in view on every settings page, and makes wardrobe paging much faster.
It supersedes v1.0.48 and v1.0.49, which were never published.

## What's new

- Settings now show your cat in a large square at the top of the side rail.
  The rail stays in place while pages scroll, so your cat and outfit are always
  visible. On short windows the square shrinks so every page tab stays on
  screen.
- Buttons and sections use thin warm borders with soft shadows, and buttons
  lift gently on hover. Navigation tabs stay flat until hovered or selected.
- Hover effects and switches now animate smoothly. Animations are skipped when
  Windows animation effects are turned off.
- Settings use Segoe UI Variable on Windows 11, with smoother sliders and
  switches and a slimmer, neutral scrollbar.
- On Windows 11, the settings window has rounded corners and a warm border.
- Moving between wardrobe pages is now near-instant instead of pausing for
  about a second, and settings sections redraw much faster when they resize.

## Downloads and updates

Use **Check for updates** in Cat Type, or quit the app before updating manually.
