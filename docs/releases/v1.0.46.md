# Cat Type v1.0.46

This release adds a themed settings window and pagination for the wardrobe and
achievements, and speeds up opening settings.

## What's new

- Added a themed settings window frame with rounded surfaces and keyboard
  scrolling support.
- Paginated wardrobe accessory tiles and achievement rewards with shared
  pagination controls.
- Settings pages and previews now build lazily, so settings open faster.
- Wardrobe cards now stack and wrap their text at enlarged text sizes, and new
  badges stay visible.
- Fixed scrollbar and layout oscillation in the wardrobe and settings windows.
- Preview rendering now recovers from deferred failures.

## Downloads and updates

Use **Check for updates** in Cat Type, or quit the app before updating manually.
