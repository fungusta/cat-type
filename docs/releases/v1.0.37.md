# Cat Type v1.0.37 Beta

This beta expands your cat's wardrobe and adds more ways to discover accessories.
Installing this designated beta unlocks **Beta Buddy** and an exclusive purple
bandana with a gold β emblem. Keep it permanently when you upgrade to stable.

## What's new

- Separate **Wardrobe** and **Achievements** tabs for outfits and progress.
- **Nine new achievements**, each unlocking an equippable item.
- New **neckwear**, **back accessories**, and **ear accessories** slots that
  combine with existing hats and glasses: bow ties, bandanas, scarves, pendants,
  capes, wings, and a flower clip.
- **Secret achievements and rewards** stay hidden until you earn them, then
  appear immediately without reopening Settings or losing pending outfit choices.
- More public milestones: Helping Paw, Daily Purr, Faithful Feline, and Million Meows.

Your existing activity counts, rewards, and outfits carry forward. Older activity
date formats load correctly, and achievement tracking stays fast with large histories.

## Downloads

- **Windows x64:** download and run `Cat-Type-Windows-x64.exe`.
- **macOS:** choose the signed and notarized DMG for Intel (`x64`) or Apple silicon (`arm64`).
- **Linux:** extract the archive matching your architecture and run `Cat Type`.

This is a **beta prerelease**. Stable installations do not automatically update to
beta releases; install the appropriate download manually. Quit Cat Type before updating.
`SHA256SUMS.txt` contains checksums for all five downloads.
