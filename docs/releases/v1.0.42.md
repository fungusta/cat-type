# Cat Type v1.0.42

This release makes newly earned achievements and wardrobe rewards easier to notice.

## What's new

- Added `NEW` badges to newly unlocked achievement cards and wardrobe items.
- Added an Achievements tab marker that stays visible until the page is opened.
- Added tray title and Settings menu indicators when rewards are earned while Settings is hidden.
- Preserved the existing unlock toast, reward persistence, and click-through typing behavior.

Existing preferences, activity counts, outfits, and earned rewards carry forward.

## Downloads and updates

- **Windows x64:** download and run `Cat-Type-Windows-x64.exe`.
- **macOS:** choose the signed and notarized DMG for Intel (`x64`) or Apple silicon (`arm64`).
- **Linux:** extract the archive matching your architecture and run `Cat Type`.

Use **Check for updates** in Cat Type, or quit the app before updating manually.
`SHA256SUMS.txt` contains checksums for all five downloads.
