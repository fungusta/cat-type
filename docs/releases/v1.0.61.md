# Cat Type v1.0.61

This release lets Cat Type on Mac update itself, and adds a guided setup for
Input Monitoring.

## What's new

- **Mac updates install themselves.** When a new version is out, Cat Type
  offers **Install Update**, **Remind Me Later**, or **Skip This Version**.
  Install Update downloads the new version, checks Apple's signature and
  notarization, swaps it into place, and reopens Cat Type. If the prompt
  appears while you're typing elsewhere, it won't take your keyboard.
  Self-update works when Cat Type is in Applications (or another folder you
  can write to); otherwise it links to the download.
- **Daily update checks while running.** Cat Type now looks for updates while
  it's open, not only at launch, on every platform. On Windows and Linux an
  automatic update prompt defaults to **No**, so a stray Return can't install.
- **Input Monitoring setup guide.** On Mac, a setup window explains why Cat
  Type needs Input Monitoring, shows which switch to flip, opens the right
  System Settings pane, and notices when access arrives. It's also in the menu
  bar as **Set Up Input Monitoring…**.
- **Secure Keyboard Entry warning.** When another app holds Secure Keyboard
  Entry, the menu bar names it and links to help.

## Downloads and updates

Mac users on 1.0.60 or earlier need to install this version by hand one last
time; later versions can update themselves. On Windows and Linux, use **Check
for updates** in Cat Type, or quit the app before updating manually.
