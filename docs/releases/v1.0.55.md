# Cat Type v1.0.55

This release polishes the settings window on macOS.

## Fixes

- **Light title bar in Dark Mode.** On macOS with Dark Mode on, the settings
  window's title bar is now light to match the rest of the window, as it is on
  Windows.
- **Smooth trackpad scrolling.** Two-finger swipes on a Mac trackpad now scroll
  settings pages smoothly instead of jumping a large step at a time.

Scrolling with a mouse wheel and everything on Windows and Linux are unchanged.

## Downloads and updates

Use **Check for updates** in Cat Type, or quit the app before updating manually.
