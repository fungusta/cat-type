# Cat Type v1.0.39

Settings now save automatically as you change them. Choose your cat, adjust its
behavior, or change an outfit without pressing Save.

## What's new

- All settings and wardrobe choices save and apply automatically while the
  settings window stays open.
- **Close** replaces **Save changes** and **Cancel**. Closing keeps your changes.
- The size slider saves after a brief pause to keep dragging smooth; closing
  immediately still saves the final size.
- If saving fails, the window shows an error and retries before closing.
- Settings stay in sync with tray pauses, and unrelated edits preserve pending
  macOS Input Monitoring permission requests.

Your existing preferences, activity counts, outfits, and earned rewards carry
forward. This is a stable release.

## Downloads and updates

- **Windows x64:** download and run `Cat-Type-Windows-x64.exe`.
- **macOS:** choose the signed and notarized DMG for Intel (`x64`) or Apple silicon (`arm64`).
- **Linux:** extract the archive matching your architecture and run `Cat Type`.

Use **Check for updates** in Cat Type, or quit the app before updating manually.
`SHA256SUMS.txt` contains checksums for all five downloads.
