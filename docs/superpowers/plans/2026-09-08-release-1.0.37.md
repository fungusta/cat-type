# Cat Type v1.0.37 beta release

**Goal:** Publish the approved secret achievement items as a designated beta.

**Scope:** Include separate wardrobe/achievement tabs, nine new item rewards,
three equipment slots, secret discovery, Beta Buddy, and compatibility/performance
fixes. Keep all existing rewards and user settings. The user authorized release.

## Constraints

- New immutable tag `v1.0.37`; synchronize all four platform metadata files.
- Keep `IS_BETA_BUILD=True`; publish as a prerelease without replacing latest stable.
- Ship the Windows installer, signed/notarized Intel and ARM macOS DMGs, both Linux
  archives, and SHA256SUMS.txt using the existing five-platform release workflow.
- Release notes describe discovery without revealing secret requirements.
