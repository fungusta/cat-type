# Cat Type v1.0.38 stable release plan

**Goal:** Publish the approved achievement and wardrobe features to stable users.

**Architecture:** Build a new v1.0.38 release with `IS_BETA_BUILD=False` through
the existing five-platform Release workflow. Preserve the published v1.0.37 beta
and permanent Beta Buddy unlocks already earned there.

**Tech stack:** Python, Tk, PyInstaller, Inno Setup, GitHub Actions, macOS notarization.

## Constraints

- User explicitly requested stable publication after the beta release.
- Keep v1.0.37 immutable; v1.0.38 must become the latest stable release.
- Fresh stable installations must not receive Beta Buddy; existing beta rewards persist.
- Preserve all wardrobe/achievement functionality and hide secret conditions in notes.
