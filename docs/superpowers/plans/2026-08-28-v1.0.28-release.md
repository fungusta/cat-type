# Cat Type v1.0.28 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified Windows updater fix and baseline test corrections as Cat Type v1.0.28.

**Architecture:** Keep the release mechanics unchanged: synchronize all version-bearing files, verify the exact release candidate locally, push `main`, gate tagging on the cross-platform build, then push one immutable annotated tag so the existing Release workflow builds and publishes all platform assets. Audit the resulting GitHub Release and checksums before reporting completion.

**Tech Stack:** Python 3.12, `unittest`, Git, GitHub CLI, GitHub Actions, PyInstaller, Inno Setup

## Global Constraints

- Release version is `1.0.28`; the immutable annotated tag is `v1.0.28`.
- Preserve every existing public tag and never move, delete, or reuse a release tag.
- Do not push the release tag unless local verification and the pushed-main cross-platform build succeed.
- The release is complete only when the tag workflow succeeds and the public release contains five non-empty platform packages plus `SHA256SUMS.txt`.
