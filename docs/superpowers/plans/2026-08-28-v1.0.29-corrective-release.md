# Cat Type v1.0.29 Corrective Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Correct the native-window-manager-dependent small-screen layout assertion and publish the Windows updater fix as Cat Type v1.0.29.

**Architecture:** Keep production sizing behavior unchanged and replace only the invalid exact native-height assertion with portable bounds while retaining real overflow and scrollbar coverage. Validate the release candidate locally, push it to `main`, and run both the normal three-platform build and a manual five-platform release dry run on `main` before creating the immutable v1.0.29 tag.

**Tech Stack:** Python 3.12, Tk 8.6, `unittest`, Git, GitHub CLI, GitHub Actions, PyInstaller, Inno Setup

## Global Constraints

- Do not modify `settings_window.py`; the diagnosed failure is test-only.
- Preserve the pinned 800-pixel screen height and `(5000, 5000)` reported maximum size.
- Preserve the content-remeasurement, real-overflow, and mapped-scrollbar assertions.
- Preserve the failed public `v1.0.28` tag; never move, delete, or reuse it.
- Release version is `1.0.29`; the new immutable annotated tag is `v1.0.29`.
- Do not create `v1.0.29` until the five-platform dry run on `main`, including macOS arm64, succeeds.
- Publication requires five non-empty platform packages plus `SHA256SUMS.txt`.
